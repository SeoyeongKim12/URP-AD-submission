# URP-AD — ADCS-ADL 기반 의존도 지표 검증 및 대안 채점법 개발

CPAD 알츠하이머 3상 자료(AD-1061·1063·1064)로, 일상생활 설문(**ADCS-ADL**)을 이용해 돌봄 의존도(**Dependence Scale, DS**)를 예측·검증한 연구.

제출 구조는 **`code / data / result` 세 폴더**로 정리했다.

```
├── code/     ← 분석 스크립트·노트북·리포트
├── data/     ← 데이터 명세서 + 접근 안내 (환자 원본은 드라이브 전용)
└── result/   ← 집계 결과(계수·채점표·성능표·그림)
```

## 폴더 상세

### code/  (기여 브랜치별)
| 폴더 | 담당 | 내용 |
|---|---|---|
| `code/sjlee/` | 독립검증 | 전처리 재현검증 · Aim 1 타당성 · B1/B2 개발·검증 · Aim 3 검증 |
| `code/sy/` | 대안모형 개발 | 전처리 산출 · B1/B2/B3 개발·시행착오 · 보조검증 · 문항축소 |
| `code/ksy/` | Aim 3 종단분석 | 가~라 종단 분석 · 혼합모형(R) · 7문항 test |

### data/
환자 원본은 **공개 불가(DUA)** → **명세서 + 접근 안내**만. 실제 데이터는 팀 드라이브. (`data/README.md` 참고)

### result/
각 기여 브랜치의 **집계 결과물**(계수·채점표·성능표·요인적재량·그림). **환자단위 예측 CSV는 제외**(드라이브).

## 연구 요약
- **Aim 1**: 기존 A0·A1 검증 — A1이 단계 재현은 우수하나(가중카파 0.498) 돌봄부담 구분은 최저 → '단계 ≠ 부담' 반전.
- **Aim 2**: 21→**7문항** 대안 채점표 — A1보다 정확(test MAE 0.538)·A0급 안전(중증놓침 19.4%).
- **Aim 3**: 종단에서도 정확도·순위 우위, 단 보수적·분산축소 특성 병기.

## ⚠️ 데이터·재현
환자단위 데이터(`USUBJID` 포함)는 **git에 없다**(민감정보 → 드라이브 전용). 재현하려면 드라이브에서 데이터를 받아 `~/Downloads/`에 두고 `code/`를 실행. 상세는 `data/README.md` 및 `data/명세서/`.

## 환경
python 3.x · numpy · pandas · scikit-learn · scipy · matplotlib. (Aim 3 혼합모형만 R lme4/lmerTest.)
