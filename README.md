# URP-AD — ADCS-ADL 기반 의존도 지표 검증 및 대안 채점법 개발

CPAD 알츠하이머 3상 자료(AD-1061·1063·1064)로, 일상생활 설문(**ADCS-ADL**)을 이용해 돌봄 의존도(**Dependence Scale, DS**)를 예측·검증한 연구.

제출 구조는 **`code / data / result` 세 폴더**로 정리했다.

```
├── code/     ← 분석 스크립트·리포트 (00_eda ~ 04_aim3, 단계 순서)
├── data/     ← 데이터 명세서 + 접근 안내 (환자 원본은 드라이브 전용)
└── result/   ← 집계 결과(계수·채점표·성능표·그림)
```

## 폴더 상세

### code/ (분석 단계별)

| 폴더 | 내용 |
|---|---|
| `code/00_eda/` | 초기 탐색적 데이터 분석 (ADCS-ADL 문항 분포·결측 패턴) |
| `code/01_전처리/` | 원자료(CPAD qs.csv/dm.csv) → 파생지표 전처리 스크립트 + 독립 재현검증. **직접 돌릴 필요 없음** — 완성된 csv를 드라이브에서 받아 바로 쓰면 됨(아래 참고) |
| `code/02_aim1/` | 기존 알고리즘 A0·A1 타당도 검증 (01~06번 분석 + 07번 독립 재검증) |
| `code/03_aim2/` | B1(21문항 탐색) → B2(7문항 확정) 대안 채점법 개발 파이프라인 (01~06번, 하위폴더 없이 평면 구조) |
| `code/04_aim3/` | 종단 반응성 검증(단계변화 일치도 → SRM 반응성 → 혼합모형 유의성 → 해석) + 공분산구조 민감도분석(R) |

각 폴더 안 스크립트는 실행 순서대로 번호가 매겨져 있고, `_report.md`가 붙은 파일은 해당 스크립트의 개별 실행결과 리포트, 폴더 최상단의 `AimN_결과.md`는 그 aim의 종합 요약이다.

### data/
환자 원본은 **공개 불가(DUA)** → **명세서 + 접근 안내**만. 실제 데이터는 팀 드라이브. (`data/README.md`, `data/명세서/` 참고)

### result/
`code/`의 단계 구분과 대응되게 정리(`result/02_aim1/`, `result/03_aim2/최종/`·`보조검증/`, `result/04_aim3/`). **환자단위 예측 CSV는 제외**(드라이브).

## 실행 방법

1. 위 6개 파일을 `~/Downloads/`에 둔다.
2. 순서대로 실행한다: `02_aim1`(01→07번) → `03_aim2`(01→06번) → `04_aim3`.
   ```bash
   python code/02_aim1/01_preliminary.py
   ...
   python code/03_aim2/05_b2_test_and_scoretable.py
   ...
   python code/04_aim3/01_aim3.py
   ```
3. `04_aim3`의 R 스크립트(`02_Aim3_공분산_민감도분석.R`)만 별도로 `Rscript`로 실행한다.
   ```bash
   Rscript code/04_aim3/02_Aim3_공분산_민감도분석.R
   ```
4. `code/00_eda/`, `code/01_전처리/`는 원자료(raw qs.csv/dm.csv)부터 처음부터 재현할 때만 필요 — 위 6개 csv를 이미 받았다면 건너뛰어도 된다.

## 연구 요약
- **Aim 1**: 기존 A0·A1 검증 — A1이 단계 재현은 우수하나(가중카파 0.498) 돌봄부담 구분은 최저 → '단계 ≠ 부담' 반전.
- **Aim 2**: 21→**7문항** 대안 채점표 — A1보다 정확(test MAE 0.538)·A0급 안전(중증놓침 19.4%).
- **Aim 3**: 종단에서도 정확도·순위 우위는 유지되나, SRM 등 반응성 지표 우위는 척도 폭 차이·확률가중평균의 분산압축에 상당 부분 기인 — 진짜 반응성 우위로 과대해석하지 않고 병기.

## ⚠️ 데이터·재현
