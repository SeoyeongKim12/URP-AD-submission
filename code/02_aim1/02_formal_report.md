## B6. 2015판(A1) 과대평가 진단 독립검정

가설: A1이 초기 AD에서 의존도를 과대평가 → 실측 DS 대비 A1 과대평가가 특정 bADL/iADL 손상 패턴에 집중되는가.

> **정의 주의(sjlee)**: 지시서의 'iADL 온전 + bADL 비만점'에서 '완전 온전'은 6명뿐(AD 집단은 iADL이 먼저 손상)이라, iADL '온전'을 **상대적 보존(손상≤2)**으로 근사함. 방향(iADL 보존·bADL 손상 → 과대평가)은 아래 그리드에서 실제로 재현됨. 대조군으로 임상서명(bADL 온전+iADL 손상)도 함께 보고.

- bADL 문항 6개, iADL 문항 18개 사용, n=2203

### (1) 연속 관계 — A1 과대평가폭(A1−DS) vs 도메인 손상수
- Spearman(과대평가폭, bADL손상수) = +0.285 (p=1.84e-42)
- Spearman(과대평가폭, iADL손상수) = +0.113 (p=1.04e-07)
  (bADL 상관이 iADL보다 크면 → A1 과대평가를 주로 **bADL 손상**이 견인. 도메인별 분해는 (2) 그리드로.)

### (3) 지시서 문구 플래그: 'iADL 온전(근사, 손상≤2) + bADL 비만점'
- 패턴 해당 인원: 4 / 2203
- 과대평가율(≥1): 패턴 내 **75.0%** vs 패턴 외 29.3%
- Fisher exact: OR=7.24, p=7.88e-02

### (4) 임상서명 플래그: 'bADL 온전 + iADL 비만점(손상≥1)'
- 패턴 해당 인원: 1014 / 2203
- 과대평가율(≥1): 패턴 내 **13.0%** vs 패턴 외 43.3%
- Fisher exact: OR=0.20, p=2.09e-57

### 결론 (자동 산출)
- A1 과대평가(≥1)율: bADL 비만점 **43.4%** vs bADL 온전 13.0% → 과대평가는 **bADL 손상**이 주도.
- bADL 손상자 내에서 iADL이 보존될수록 과대평가율↑(그리드 참조) → 지시서 패턴 'iADL 보존+bADL 손상'이 과대평가 최정점. 다만 완전-iADL-온전은 표본이 작아 극단 플래그(3)는 검정력 부족(n=4).
- 종합: **A1의 과대평가는 bADL 경미손상을 2015판 규칙이 과벌점하는 데서 비롯**(2단계↑ 과대평가 6.4%). 실측 DS 기준 진단 성립.
