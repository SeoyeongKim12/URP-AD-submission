## S2. 비위계(non-hierarchical) 실측 DS 응답자 제외

- DS 위계 가정: 더 심한(상위 티어) 문항을 의존하면 덜 심한(하위 티어) 문항도 의존해야 함. 위반 = 상위 티어 문항을 endorse(=1)했는데 그 아래 어떤 티어는 전부 0(건너뜀).

> 조작적 정의(sjlee): 티어 [DS01-04 / DS05-07 / DS08-10 / DS11-13]에서 각 티어 endorse 여부를 구해, '최고 endorse 티어보다 낮은 티어 중 하나라도 endorse=0'이면 비위계로 판정.

- 기저 DS 완전관측 2208명 중 비위계 **59명 (2.7%)**

### 비위계 유형 (최고 endorse 티어 × 건너뛴 하위 티어)
-   34명: 최고=T5, 건너뜀=T4
-    8명: 최고=T5, 건너뜀=T3+T4
-    8명: 최고=T4, 건너뜀=T3
-    5명: 최고=T3, 건너뜀=T_low
-    3명: 최고=T5, 건너뜀=T3
-    1명: 최고=T5, 건너뜀=T_low+T3
