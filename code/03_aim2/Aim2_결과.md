# Aim 2 종합 결과 — B1 대안 채점법 + 조건3 구제(Gn) (sjlee)

분석일: 2026-08-05 (튜닝 통일 갱신: 2026-08-13)  |  상태: **B1 미충족 → Gn이 A1 양지표 지배 + 중증 A0수준(중증우선 통일)**
※ 튜닝 통일: 전 모형을 **중증우선**(제약=중증놓침 ≤ A0, 목적=MAE최소)으로 통일. 판정도 4조건→**A1 지배+A0 안전**으로 정렬.
코드: `b1_proportional_odds.py`(원 B1), `b1_improve.py`(대안 A~F·G), `b1_gn_elasticnet.py`(정식 Gn),
`b1_penalty_probe.py`(벌점 견고성)  |  전제: Aim 1 완결(A1 기준선 카파 0.498/MAE 0.591)

> **목표**: ADCS-ADL 문항점수로 실측 DS 단계(0–5)를 예측하는 해석가능 순서형 모형을 개발,
> leave-one-trial-out 3-fold CV로 A1과 **추가가치 4조건**을 비교. 충족 시 B2(문항축약)로.

## 0. 핵심 결과 요약 (한눈에)

1. **원 B1(비례오즈)은 미충족**: 평균 정확도(MAE·카파·±1)는 A1보다 좋으나, **중증(4·5)을 3 이하로 62% 오분류**(A1 27%) → 조건 3 대폭 실패(+35.2%p).
2. **원인**: 순서형 모형이 평균오차 최소화로 예측을 중간(2·3단계)에 압축 → 드문 중증을 놓침(calibration: 실측 4단계→평균예측 3.4).
3. **구제 성공(Gn)**: **부분비례오즈(비평행 엘라스틱넷) + 비대칭 임계(중증우선 τ)**로,
   중증놓침을 **A0 수준(≈18%)으로 억제**하면서 MAE·카파는 A1을 이김 → **A1 양지표 지배 + 중증 A0수준**.
4. **메커니즘**: 비평행 모형이 **각 심각도 절단에 다른 문항 가중**을 허용 — 상위 절단(중증)은
   기본 ADL, 하위 절단은 iADL이 주도 → 중증 신호를 살림(아래 §4 계수).
5. **한계**: 앙상블 구조(단일 채점표 취지 약화), 3시험 소표본. **AD-1062 외부검증 통과**(§7, 중증 17.4%).

## 8. ④ B2 문항축약 정식 — `b2_item_selection.py`

Gn 위에서 fold 내부 문항선택(누출0), 안정성선택 top-K·λ상향 두 경로.

- **τ 튜닝(정정)**: 중증놓침을 훈련 A0 수준으로 **고정**하고 그 안에서 **MAE 최소화**(제약=중증우선, 목적=MAE).
  초기판은 제약/목적이 뒤바뀌어(MAE우선) 중증놓침이 부풀었음 → 수정.
- **정렬된 3겹 관문(내부보존 + A1 양지표 지배 + 중증 ≤A0+2%p) 통과 최소 = 8문항.**
  8문항: 목욕·외출·금전·몸단장·화장실·식사준비·지불·전화. MAE 0.523, 중증 18.8%(A0수준 유지), A1 양지표 지배.
  7↓는 중증놓침이 A0+2%p 초과(안전 실패).
- 안정성선택 6문항 3/3 공통 = **외출·화장실·목욕·몸단장·금전** (전수조사 4핵심과 수렴 → 신뢰도↑).
- λ상향은 문항 잘 안 죽음(elastic-net L2성분) → 주경로는 안정성선택.
- 최종 8문항 **원눈금 축약 채점표**(`b2_reduced_scoretable.csv`) + 선택빈도표(`b2_selection_frequency.csv`).
- 참고: 발표의 'MAE 감소≥0.10' 4조건은 *MAE우선* 튜닝(발표 Gn, MAE 0.455) 기준. 중증우선판과는 판정틀이 다름.
- **한계**: 독립검증된 단축형이 아니라 본 자료서 성능 유지하며 줄인 후보(외부검증 전 낙관적).

## 9. ⑤ 구조분석 (탐색) — `aim2_structure.py`

**위상: 탐색·기술**(확증 아님, 주결론 불변).

- **PCA**: PC1 31.8% 지배(전반 중증도축), Kaiser 5성분(누적 56%).
- **EFA 4요인**: F1 옷·자기관리 / F2 지역·금전 iADL / F3 집안일 iADL → iADL이 지역·가정으로 분리.
- **군집 k=2**(실루엣 0.273): 고중증 vs 저중증 = 연속 중증도 스펙트럼(뚜렷한 하위유형 약함).
- B2 선택문항이 F1·F2·전반축을 고르게 대표 → 축약의 구조적 타당성 뒷받침.
- 한계: 순서형 피어슨 근사(polychoric 미사용), varimax 폴백, 비지도라 판정 아님.
