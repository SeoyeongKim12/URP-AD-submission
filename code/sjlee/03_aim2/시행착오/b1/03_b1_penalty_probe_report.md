# Aim 2 · 부분비례오즈 벌점 강도·유형 탐색 (sjlee)

각 벌점에서: (1) C+임계(mae_thr=0.10) 결과, (2) 예산마진 스윕에서 4조건(주0.10) 통과하는
train감소목표 구간과 그때 조건3 여유. **조건3 여유(+2%p 한도까지 거리)가 클수록 견고.**

| 벌점 | C+임계 4·5→≤3 | 4조건통과 마진구간 | 그중 조건3(여유) |
|---|---|---|---|
| L2 C=0.1(강벌점) | 21.8% | 0.10~0.14 | 21.8% (여유 +7.0%p) |
| L2 C=0.25 | 22.2% | 0.10~0.14 | 22.2% (여유 +6.6%p) |
| L2 C=0.5 | 22.2% | 0.10~0.14 | 22.2% (여유 +6.6%p) |
| L2 C=1.0(기존) | 22.5% | 0.12~0.14 | 23.3% (여유 +5.5%p) |
| L2 C=2.0(약벌점) | 22.5% | 0.12~0.14 | 23.3% (여유 +5.5%p) |
| ElasticNet C=0.5,l1=.5 | 22.3% | 0.10~0.14 | 22.3% (여유 +6.5%p) |
| ElasticNet C=0.25,l1=.5 | 21.6% | 0.10~0.14 | 21.6% (여유 +7.2%p) |

- '4조건통과 마진구간'이 넓고 '조건3 여유'가 클수록 그 벌점이 Gn을 견고하게 함.
- 기존(L2 C=1.0) 대비 개선되는 벌점이 있으면 그걸로 Gn 재확정 권장.
