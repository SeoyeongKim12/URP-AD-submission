# Aim 2 · 12문항 vs 13문항 최종 후보 (sjlee)

기준 A1 MAE 0.589 / A0 중증놓침 17.7%. 중증우선 CV(목표=훈련A0).

## 12문항 (12개)
- 문항(영역): 목욕(F4), 외출(F2), 금전(F2), 몸단장(F4), 화장실(F4), 식사준비(F1), 지불(F2), 전화(F2), 혼자(F2), 쇼핑(F2), 걷기(F4), 입기(F1)
- **성능: MAE 0.526 / 중증놓침 17.4% / 카파 0.574**
- 시험별 중증놓침: {AD-1061:23.4%, AD-1063:13.5%, AD-1064:16.7%}
- FA축 커버: ['F1옷·식사', 'F2지역·금전', 'F4기초'] (3/4)
- 조건: 핵심4고정 ✅ / MAE≤A1 ✅ / 중증≤A0 ✅ / 4축커버 ❌ → **일부 미충족**

## 13문항 (13개)
- 문항(영역): 목욕(F4), 외출(F2), 금전(F2), 몸단장(F4), 화장실(F4), 식사준비(F1), 지불(F2), 전화(F2), 혼자(F2), 쇼핑(F2), 걷기(F4), 입기(F1), 설거지(F3)
- **성능: MAE 0.528 / 중증놓침 17.7% / 카파 0.573**
- 시험별 중증놓침: {AD-1061:23.4%, AD-1063:13.5%, AD-1064:17.5%}
- FA축 커버: ['F1옷·식사', 'F2지역·금전', 'F3가사', 'F4기초'] (4/4)
- 조건: 핵심4고정 ✅ / MAE≤A1 ✅ / 중증≤A0 ✅ / 4축커버 ✅ → **4조건 전부 충족**

## 요약
- **13 = 12 + 설거지**. 12는 성능조건(MAE≤A1·중증≤A0)만 최소, 가사(F3)축 빠짐(4조건 중 축균형 미충족).
- **13은 설거지로 가사축까지 커버 → 4조건 전부 충족.** 문항 1개 더로 축균형 확보.
- 두 안 성능 차이는 미미(노이즈 범위). 선택은 '축균형(4조건)까지 지킬지'로 귀결.
