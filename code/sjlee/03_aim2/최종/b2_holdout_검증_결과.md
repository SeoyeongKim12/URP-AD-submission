## 업무 ① 최종후보 테스트셋 1회 검증

**프로토콜**: 개발셋(1,652) 전체로 적합 + τ4·τ5 튜닝(A0-목표) → **테스트셋(551)에 딱 1회** 예측.
추가검증 8개 후보를 한 번씩 올려 비교. **최종 확정 = 7문항(고정6 + Q7전화)** — Q17금전은 Q7전화와 같은 요인축이라 제외(파시모니). 테스트 순위로 고른 게 아니라 구조(같은 축)+규칙(최대축소)로 결정, 테스트는 확인용.

**결과 — TEST 551명** (추가검증 페이지 8개 후보 전부 1회씩)

| 후보 | MAE | 중증놓침 | 카파 | ±1 | 정확 |
|---|---|---|---|---|---|
| 7문항 주 (+Q17금전) | 0.561 | 20.8% | 0.545 | 90.9% | 53.2% |
| **★ 7문항 확정 (+Q7전화)** | **0.538** | **19.4%** | **0.570** | 91.4% | 54.9% |
| 8문항 주 (+Q7전화, Q17금전) | 0.560 | 20.8% | 0.550 | 90.7% | 53.5% |

| 8문항 보조2 (+Q1먹기, Q17금전) | 0.568 | 19.4% | 0.543 | 90.9% | 52.5% |
| 9문항 주 (+Q6b, Q17, Q23) | 0.561 | 19.4% | 0.542 | 90.5% | 53.6% |

| 9문항 보조2 (+Q1, Q6b, Q22) | 0.555 | 18.1% | 0.545 | 90.1% | 54.6% |
| *(참고) A1* | 0.590 | 34.7% | 0.487 | — | — |
| *(참고) A0* | 0.833 | 20.8% | 0.434 | — | — |

★ = 최종 확정 (고정6 + Q7전화)

**결론**
- **8개 후보 전부 A1 지배** — MAE(0.538~0.568 < 0.590)·중증놓침(18~22% ≪ 34.7%) 모두 우세.
- **중증안전**: 9문항 보조1(22.2%)만 A0(20.8%)보다 살짝 나쁘고, **나머지 7개는 A0 이하**.
- 후보 간 차이는 사실상 **노이즈 수준**이고, **7문항(+Q7전화)만으로도 최고 성능과 동급**(MAE 0.538로 최상위) → 문항을 더 넣어도 이득 없음.
- **확정 7문항**: 테스트에서 **A1 지배 + A0급 중증안전(19.4% ≤ 20.8%)** 확인. Q7·Q17은 같은 축이라 Q17 제외해도 정보 손실 없고 문항만 하나 줄어듦(규칙4).

## 업무 ② 원눈금 채점표

**대상**: 확정 8문항(fixed6 + Q7전화 + Q17금전), 개발+테스트(2,194명) 재학습.

**산출 파일** (`aim2/시행착오/`)
- `b2_scoretable_8item_raw.csv` — 절단별(P(Y≥1)~P(Y≥5)) 릿지 계수·절편 (원눈금 + 표준화)
- `b2_scoretable_8item_rule.csv` — 판정규칙

**τ 판정규칙**: τ4 = 0.08, τ5 = 0.58

**적용법**
1. 각 절단 P(Y≥k)를 로지스틱(원눈금 계수·절편)으로 계산 → 단계별 확률 P(Y=0..5) 조립.
2. 예측단계 = `5 if P(Y=5) > 0.58` · `elif 4 if P(Y≥4) > 0.08` · `else 조건부중앙값`.
