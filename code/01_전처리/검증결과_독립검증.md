## C2. 게이팅 3분기 규칙 감사

규칙: 부모 관문 = `not_generated`(N) → `__resolved` 전부 0 / `dont_know` → NaN 유지 / `generated`(Y) → 원값 유지.

**중요 발견 (검증 방법 자체의 함정)**: gate 컬럼은 두 종류임 —
- **부모 관문질문** 컬럼(`ADL0106__gate` 등): `{generated, not_generated, dont_know}` ← 게이팅을 지배
- **하위문항** 컬럼(`ADL0106B__gate` 등): `{other, missing}` ← 그 칸이 원자료에 비었는지만 표시

하위문항 자체의 `__gate`로 판정하면 오탐이 남. **부모 관문질문 기준**으로 판정해야 함.

- 27개 `__resolved` 전부 부모 관문 3분기 규칙 준수. **PASS.**
- 판정노트: `ADL0106`(옷입기)은 하위 A(Q6a 옷 고르기)만 관문에 종속되고, B(Q6b 입기)는
  직접 응답되는 별도 문항임(관문 DK여도 B는 실제 응답값 보존이 정상). 교차표로 확인:
  `ADL0106__gate=generated`(8,200)→A 전부 값 / `not_generated`(1,474)→A 전부 0 / `dont_know`(9)→A 전부 NaN.
  A는 관문에 완벽히 종속, B는 독립. 팀원 처리 정확.
