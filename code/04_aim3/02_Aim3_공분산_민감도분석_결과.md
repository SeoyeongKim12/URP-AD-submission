## 1. 왜 R로 별도 실행하나

Python(statsmodels/scikit-learn) 쪽에는 참가자별 랜덤절편+랜덤기울기를 갖는 선형혼합모형(LMM)의 Satterthwaite 근사 표준오차를 안정적으로 계산하는 표준 도구가 마땅치 않아, 이 부분만 R의 `lmerTest`(Satterthwaite df 보정)로 별도 재현했습니다. 나머지 가·나·라절은 전부 Colab/Python 파이프라인입니다.

## 2. 모형 구조

- 결과변수: `Y_std` (실측 DS총점 또는 B2 기대단계, 표준화)
- 고정효과: `Visit(V2/V5/V7) + STUDYID + Treatment`
- 랜덤효과: 주분석 = 랜덤절편만 `(1 | USUBJID)` / 민감도분석 = 랜덤절편+기울기 `(1 + time_num | USUBJID)`

### 2-1. 왜 범주형 Visit 대신 연속시간(time_num)을 랜덤기울기에 쓰는가

Visit(V2/V5/V7)을 범주형 그대로 랜덤기울기에 넣으면 참가자당 필요한 임의효과가 3개(절편+V5기울기+V7기울기)가 되는데, 전체의 약 10%가 2개 시점만 관측되어 있어 **임의효과 수가 관측치 수를 초과** → `number of observations <= number of random effects` 에러로 적합 자체가 불가능했습니다. `time_num`(0/12/24, 연속)으로 바꿔 참가자당 임의효과를 2개(절편+기울기)로 줄이자 식별 가능해졌습니다. 이는 임시방편이 아니라 **이 데이터 구조(불균형 방문횟수)에서 유일하게 수렴하는 정식화**입니다.
