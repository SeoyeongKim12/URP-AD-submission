# 데이터 명세서

이 문서는 ① 실행에 필요한 **입력 데이터**(어디서 받아 어디에 두나), ② 이 저장소에 올라와 있는 **결과 파일**이 각각 무엇인지, ③ **실행법**을 정리한다.

> **데이터 원칙**: 환자단위 파일(행 = 환자, `USUBJID` 포함)은 **git에 올리지 않는다**(민감정보 → 드라이브 전용, `.gitignore` 차단). 이 저장소에 커밋된 CSV는 **전부 집계·계수·규칙 표**(환자 식별 불가)뿐이다.

## 2. code/ ↔ result/ 매핑 (단계별)

**전부 집계·계수 표(비환자)라 git에 포함됨.** 환자단위 산출물은 §3 참조(드라이브).

### `code/00_eda/` — 초기 탐색적 분석
CPAD 원자료 문항 분포·결측 패턴 확인. 결과물은 콘솔 출력 위주(별도 result/ 없음).

### `code/01_전처리/` — 원본 전처리 + 독립 재현검증
- `01_preprocess_dependence_study.py`: 원자료(qs.csv/dm.csv) → parquet 6종 생성 (전처리를 직접 돌릴 사람만 필요, 대부분은 완성된 csv를 드라이브에서 받아 씀)
- `02_verify_independent.py`(+report), `03_verify_supervision_c4c.py`(+report): DS단계·게이팅 3분기·감독시간(C4c)을 원점수에서 재계산해 대조

### `code/02_aim1/` — Aim 1 타당성
`01_preliminary` → `02_formal` → `03_sensitivity` → `04_sensitivity_missing` → `05_supervision` → `06_supervision_sens` → `07_verify_aim1`(독립 재검증, 원자료에서 새로 계산해 대조) (+ 각 `_report.md`), 종합 `Aim1_정식결과.md`.

> **result/02_aim1/ 없음**: 이 단계 산출물은 report.md뿐이고, 실제 채점표·분석표 csv는 전부 환자단위(§3)라 git에 올릴 집계표 자체가 없음.

## 4. 실행법

1. §1의 입력 데이터를 드라이브에서 받아 **`~/Downloads/`** 에 둔다(전처리를 직접 돌릴 필요 없음 — 완성된 csv를 바로 받아 쓰면 됨).
2. 번호 순으로 실행한다: `02_aim1 → 03_aim2 → 04_aim3` (00_eda, 01_전처리는 원자료 재현이 필요할 때만).
3. 예: `python 03_aim2/05_b2_test_and_scoretable.py`
4. 환경: python 3.x · numpy · pandas · scikit-learn · scipy · matplotlib. (04_aim3의 공분산구조 민감도분석만 R lme4/lmerTest.)

> **재현 주의**: dev/test 분할은 스크립트 안에 고정된 seed(20260814) · STUDYID×ds_stage 층화 · 75/25 규칙으로 매번 동일하게 재현된다. 별도의 공식 분할 파일을 받을 필요는 없다.
